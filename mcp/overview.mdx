NorthAxium Data ships an MCP (Model Context Protocol) server that lets Claude and other AI agents query Canadian government data directly in natural language — no API calls required.

## What you can ask

Once connected, you can ask Claude questions like:

- *"What has Palantir lobbied for in Canada?"*
- *"Who are the top vendors for National Defence?"*
- *"What contracts has Shopify won from the federal government?"*
- *"Find all new construction permits in Calgary over $1M in the last year"*
- *"Which companies are lobbying the most on mining and resources?"*

Claude handles the reasoning. NorthAxium Data supplies the ground truth.
