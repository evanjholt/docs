---
title: "Authentication"
description: "How to authenticate with the NorthAxium Data API."
---

All `/api/v1/*` endpoints require an API key passed in the `X-API-Key` request header.

<CodeGroup>

```python Python
import requests

headers = {"X-API-Key": "your_api_key_here"}
response = requests.get(
    "https://api.northaxiumdata.ca/api/v1/contracts",
    headers=headers
)
```

```javascript JavaScript
const response = await fetch("https://api.northaxiumdata.ca/api/v1/contracts", {
  headers: { "X-API-Key": "your_api_key_here" }
});
```

```bash cURL
curl -H "X-API-Key: your_api_key_here" \
  https://api.northaxiumdata.ca/api/v1/contracts
```

</CodeGroup>

## Error responses

| Status | Code | Meaning |
|---|---|---|
| `401` | `UNAUTHORIZED` | Missing or invalid API key |
| `429` | `RATE_LIMITED` | Monthly request limit exceeded |

```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "Missing API key. Pass your key in the X-API-Key header."
  }
}
```

## Rate limit headers

Every authenticated response includes rate limit headers so you can track consumption:

```
X-RateLimit-Limit: 10000
X-RateLimit-Remaining: 9987
X-RateLimit-Reset: 1714953600000
```

## Unprotected endpoints

`GET /health` does not require a key and can be used to verify API reachability.
