---
title: "Infrastructure Projects"
api: "GET /grants/infrastructure"
description: "Retrieve a list of infrastructure projects funded by the Canadian government."
---

Get a standardized list of federal infrastructure funding projects, filterable by region, timeline, and project type.

### Query Parameters

<ParamField query="limit" type="integer" default="100">
  Maximum number of projects to return. Maximum limits map to your plan (100 for Basic, 1,000 for Pro, 10,000 for Enterprise).
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Number of records to skip for pagination.
</ParamField>

<ParamField query="region" type="string">
  Filter by geographic region, province, or territory (e.g., `Ontario`, `British Columbia`).
</ParamField>

<ParamField query="project_type" type="string">
  Filter by the type of infrastructure project (e.g., `Transit`, `Green Infrastructure`, `Social`).
</ParamField>

<RequestExample>

```bash cURL
curl "https://api.northaxiumdata.ca/v1/grants/infrastructure?limit=10&region=Ontario" \
  -H "X-API-Key: <your-api-key>"
```

```python Python
import requests

url = "https://api.northaxiumdata.ca/v1/grants/infrastructure"
headers = {"X-API-Key": "<your-api-key>"}
params = {
    "limit": 10,
    "region": "Ontario"
}

response = requests.get(url, headers=headers, params=params)
print(response.json())
```

```javascript Node.js
const fetch = require('node-fetch');

const url = new URL('https://api.northaxiumdata.ca/v1/grants/infrastructure');
url.search = new URLSearchParams({

  region: 'Ontario'
});

fetch(url, {
  headers: {
    'X-API-Key': '<your-api-key>'
  }
})

  .then(json => console.log(json));
```
