api: "GET /api/v1/contracts/stats"
---

## Overview

Returns grouped aggregate statistics across all federal contract records. Useful for spending breakdowns by department, vendor rankings by total value, or year-over-year procurement trends.

## Query Parameters

<ParamField query="group_by" type="string">
  Grouping dimension. Options: `department`, `vendor`, `year`. Default: `department`
</ParamField>

<ParamField query="limit" type="integer">
  Max groups to return. Default: `100`. Max: `200`
</ParamField>

<RequestExample>
```bash cURL
curl -H "X-API-Key: your_api_key_here" \
  "https://api.northaxiumdata.ca/api/v1/contracts/stats?group_by=department&limit=10"
```

```python Python
import requests

headers = {"X-API-Key": "your_api_key_here"}
params = {"group_by": "department", "limit": 10}

response = requests.get(
    "https://api.northaxiumdata.ca/api/v1/contracts/stats",
    headers=headers,
    params=params
)
print(response.json())
```
</RequestExample>
