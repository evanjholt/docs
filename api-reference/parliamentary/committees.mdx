---
title: "Committees"
api: "GET /parliamentary/committees"
description: "Retrieve a list of House and Senate committees."
---

Get a standardized list of standing, special, and legislative committees, including their current membership and mandate.

### Query Parameters

<ParamField query="limit" type="integer" default="100">
  Maximum number of committees to return. Maximum limits map to your plan (100 for Basic, 1,000 for Pro, 10,000 for Enterprise).
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Number of records to skip for pagination.
</ParamField>

<ParamField query="session" type="string">
  Filter by parliamentary session (e.g., `44-1`).
</ParamField>

<RequestExample>

```bash cURL
curl "https://api.northaxiumdata.ca/v1/parliamentary/committees?limit=10&session=44-1" \
  -H "X-API-Key: <your-api-key>"
```

```python Python
import requests

url = "https://api.northaxiumdata.ca/v1/parliamentary/committees"
headers = {"X-API-Key": "<your-api-key>"}
params = {
    "limit": 10,
    "session": "44-1"
}

response = requests.get(url, headers=headers, params=params)
print(response.json())
```

```javascript Node.js
const fetch = require('node-fetch');

const url = new URL('https://api.northaxiumdata.ca/v1/parliamentary/committees');

  session: '44-1'
});

fetch(url, {
  headers: {
    'X-API-Key': '<your-api-key>'
  }
})
  .then(res => res.json())
```
