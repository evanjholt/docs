---
title: "Bills & Legislation"
api: "GET /api/v1/parliamentary/bills"
description: "Retrieve a list of parliamentary bills and their current legislative status."
---

Get a standardized list of bills introduced in the House of Commons and the Senate, including their sponsors, stages, and summaries.

### Query Parameters

<ParamField query="limit" type="integer" default="100">
  Maximum number of bills to return. Maximum limits map to your plan (100 for Basic, 1,000 for Pro, 10,000 for Enterprise).
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Number of records to skip for pagination.
</ParamField>

<ParamField query="session" type="string">
  Filter by parliamentary session (e.g., `44-1`).
</ParamField>

<ParamField query="status" type="string">
  Filter by current status or stage (e.g., `Royal Assent`, `First Reading`).
</ParamField>

<RequestExample>

```bash cURL
curl "https://api.northaxiumdata.ca/api/v1/parliamentary/bills?limit=10&status=Royal+Assent" \
  -H "X-API-Key: <your-api-key>"
```

```python Python
import requests

url = "https://api.northaxiumdata.ca/api/v1/parliamentary/bills"
headers = {"X-API-Key": "<your-api-key>"}
params = {
    "limit": 10,
    "status": "Royal Assent"
}

response = requests.get(url, headers=headers, params=params)
print(response.json())
```

```javascript Node.js
const fetch = require('node-fetch');

const url = new URL('https://api.northaxiumdata.ca/api/v1/parliamentary/bills');
url.search = new URLSearchParams({
  limit: '10',
  status: 'Royal Assent'
});

fetch(url, {
  headers: {
    'X-API-Key': '<your-api-key>'
  }
})
  .then(res => res.json())
  .then(json => console.log(json));
```
