---
title: "Bills & Legislation"
api: "GET /api/v1/bills"
description: "Retrieve a list of parliamentary bills and their current legislative status."
---

Get a standardized list of bills introduced in the House of Commons and the Senate, including their sponsors, stages, and summaries.

### Query Parameters

<ParamField query="session" type="string">
  Filter by parliamentary session (e.g., `44-1`).
</ParamField>

<ParamField query="status" type="string">
  Filter by current bill status code.
</ParamField>

<ParamField query="sponsor" type="string">
  Partial match on sponsor name.
</ParamField>

<ParamField query="sector" type="string">
  Exact match on sector tag.
</ParamField>

<ParamField query="q" type="string">
  Partial match on bill title.
</ParamField>

<ParamField query="law" type="boolean">
  Filter enacted laws.
</ParamField>

<ParamField query="private_member" type="boolean">
  Filter private members' bills.
</ParamField>

<ParamField query="limit" type="integer">
  Results per page. Default: `50`. Max: `200`
</ParamField>

<ParamField query="offset" type="integer">
  Result offset for pagination. Default: `0`
</ParamField>

<Note>
  `page` and `per_page` are accepted as input aliases. `per_page` maps to `limit`, and `page` is converted internally into the corresponding `offset`.
</Note>

<RequestExample>

```bash cURL
curl "https://api.northaxiumdata.ca/api/v1/bills?status=ROYAL_ASSENT&limit=10&offset=10" \
  -H "X-API-Key: <your-api-key>"
```

```python Python
import requests

url = "https://api.northaxiumdata.ca/api/v1/bills"
headers = {"X-API-Key": "<your-api-key>"}
params = {
    "status": "ROYAL_ASSENT",
    "limit": 10,
    "offset": 10
}

response = requests.get(url, headers=headers, params=params)
print(response.json())
```
