---
title: "MPs & Senators"
api: "GET /api/v1/parliamentary/politicians"
description: "Retrieve a list of Members of Parliament and Senators."
---

Get a standardized list of active and historical federal politicians, their party affiliations, ridings, and roles.

### Query Parameters

<ParamField query="limit" type="integer" default="100">
  Maximum number of records to return. Maximum limits map to your plan (100 for Basic, 1,000 for Pro, 10,000 for Enterprise).
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Number of records to skip for pagination.
</ParamField>

<ParamField query="party" type="string">
  Filter by political party.
</ParamField>

<ParamField query="province" type="string">
  Filter by province or territory represented.
</ParamField>

<RequestExample>

```bash cURL
curl "https://api.northaxiumdata.ca/api/v1/parliamentary/politicians?limit=10&party=Liberal" \
  -H "X-API-Key: <your-api-key>"
```

```python Python
import requests

url = "https://api.northaxiumdata.ca/api/v1/parliamentary/politicians"
headers = {"X-API-Key": "<your-api-key>"}
params = {
    "limit": 10,
    "party": "Liberal"
}

response = requests.get(url, headers=headers, params=params)
print(response.json())
```

```javascript Node.js
const fetch = require('node-fetch');

const url = new URL('https://api.northaxiumdata.ca/api/v1/parliamentary/politicians');
url.search = new URLSearchParams({
  limit: '10',
  party: 'Liberal'
});

fetch(url, {
  headers: {
    'X-API-Key': '<your-api-key>'
  }
})
  .then(res => res.json())
  .then(json => console.log(json));
```
