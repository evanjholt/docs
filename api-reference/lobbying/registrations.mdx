---
title: "Registrations"
api: "GET /api/v1/lobbying/registrations"
description: "Retrieve federal lobbying registrations from the Registry of Lobbyists."
---

Get a standardized dataset of all active and historical lobbying registrations, detailing who is lobbying on behalf of whom.

### Query Parameters

<ParamField query="client" type="string">
  Partial match on client organization name.
</ParamField>

<ParamField query="lobbyist" type="string">
  Partial match on lobbyist name.
</ParamField>

<ParamField query="institution" type="string">
  Partial match on target institution.
</ParamField>

<ParamField query="subject" type="string">
  Partial match on subject labels.
</ParamField>

<ParamField query="active" type="boolean">
  Filter active vs inactive registrations.
</ParamField>

<ParamField query="date_from" type="string">
  ISO 8601 start date.
</ParamField>

<ParamField query="date_to" type="string">
  ISO 8601 end date.
</ParamField>

<ParamField query="limit" type="integer">
  Results per page. Default: `50`. Max: `500`
</ParamField>

<ParamField query="offset" type="integer">
  Result offset for pagination. Default: `0`
</ParamField>

<Note>
  `page` and `per_page` are accepted as input aliases. `per_page` maps to `limit`, and `page` is converted internally into the corresponding `offset`.
</Note>
