---
title: "Registrations"
api: "GET /api/v1/lobbying/registrations"
description: "Retrieve federal lobbying registrations from the Registry of Lobbyists."
---

Get a standardized dataset of all active and historical lobbying registrations, detailing who is lobbying on behalf of whom.

### Query Parameters

<ParamField query="limit" type="integer" default="100">
  Maximum number of records to return. Maximum limits map to your plan (100 for Basic, 1,000 for Pro, 10,000 for Enterprise).
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Number of records to skip for pagination.
</ParamField>

<ParamField query="status" type="string">
  Filter by the registration status (e.g., `Active`, `Inactive`).
</ParamField>

<ParamField query="client_name" type="string">
  Filter registrations by the client or corporation being represented.
</ParamField>

<RequestExample>

```bash cURL
curl "https://api.northaxiumdata.ca/api/v1/lobbying/registrations?limit=10&status=Active" \
  -H "X-API-Key: <your-api-key>"
```

```python Python
import requests

url = "https://api.northaxiumdata.ca/api/v1/lobbying/registrations"
headers = {"X-API-Key": "<your-api-key>"}
params = {
    "limit": 10,
    "status": "Active"
}

response = requests.get(url, headers=headers, params=params)
print(response.json())
```

