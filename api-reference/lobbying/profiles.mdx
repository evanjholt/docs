---
title: "Lobbyist Profiles"
api: "GET /api/v1/lobbying/profiles/{id}"
description: "Retrieve a detailed profile of a specific registered lobbyist or firm."
---

Get comprehensive data on a specific lobbyist, including their registration history, active clients, and past communications with government officials.

### Path Parameters

<ParamField path="id" type="string" required>
  The unique identifier for the lobbyist or firm (e.g., `LOB-4592`).
</ParamField>

<RequestExample>

```bash cURL
curl "https://api.northaxiumdata.ca/api/v1/lobbying/profiles/LOB-4592" \
  -H "X-API-Key: <your-api-key>"
```

```python Python
import requests

url = "https://api.northaxiumdata.ca/api/v1/lobbying/profiles/LOB-4592"
headers = {"X-API-Key": "<your-api-key>"}

response = requests.get(url, headers=headers)
print(response.json())
```

```javascript Node.js
const fetch = require('node-fetch');

fetch('https://api.northaxiumdata.ca/api/v1/lobbying/profiles/LOB-4592', {
  headers: {
    'X-API-Key': '<your-api-key>'
  }
})
  .then(res => res.json())
  .then(json => console.log(json));
```

</RequestExample>
