---
title: "List Contributions"
api: "GET /contributions/list"
description: "Retrieve a list of political contributions made to federal parties and candidates."
---

Get a standardized list of individual and corporate contributions, filterable by political party, riding, and dates. 

### Query Parameters

<ParamField query="limit" type="integer" default="100">
  Maximum number of contributions to return. Maximum limits map to your plan (100 for Basic, 1,000 for Pro, 10,000 for Enterprise).
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Number of records to skip for pagination.
</ParamField>

<ParamField query="party" type="string">
  Filter by the recipient political party (e.g., `Liberal`, `Conservative`, `NDP`).
</ParamField>

<ParamField query="riding" type="string">
  Filter contributions directed to candidates in a specific electoral district or riding.
</ParamField>

<RequestExample>

```bash cURL
curl "https://api.northaxiumdata.ca/v1/contributions/list?limit=10&party=Liberal" \
  -H "X-API-Key: <your-api-key>"
```

```python Python
import requests

url = "https://api.northaxiumdata.ca/v1/contributions/list"
headers = {"X-API-Key": "<your-api-key>"}
params = {
    "limit": 10,
    "party": "Liberal"
}

response = requests.get(url, headers=headers, params=params)
print(response.json())
```

```javascript Node.js
const fetch = require('node-fetch');

const url = new URL('https://api.northaxiumdata.ca/v1/contributions/list');
url.search = new URLSearchParams({
  limit: '10',
  party: 'Liberal'
});

fetch(url, {
  headers: {
    'X-API-Key': '<your-api-key>'
  }
})
  .then(res => res.json())
  .then(json => console.log(json));
```
