---
title: "Contributor Profiles"
api: "GET /api/v1/contributions/profiles/{id}"
description: "Retrieve political contribution history for a specific individual or organization."
---

Get a comprehensive view of all federal political contributions linked to a specific entity across multiple years, parties, and candidates.

### Path Parameters

<ParamField path="id" type="string" required>
  The unique identifier for the contributor (e.g., `CTR-48912`).
</ParamField>

<RequestExample>

```bash cURL
curl "https://api.northaxiumdata.ca/api/v1/contributions/profiles/CTR-48912" \
  -H "X-API-Key: <your-api-key>"
```

```python Python
import requests

url = "https://api.northaxiumdata.ca/api/v1/contributions/profiles/CTR-48912"
headers = {"X-API-Key": "<your-api-key>"}

response = requests.get(url, headers=headers)
print(response.json())
```

```javascript Node.js
const fetch = require('node-fetch');

fetch('https://api.northaxiumdata.ca/api/v1/contributions/profiles/CTR-48912', {
  headers: {
    'X-API-Key': '<your-api-key>'
  }
})
  .then(res => res.json())
  .then(json => console.log(json));
```

</RequestExample>
