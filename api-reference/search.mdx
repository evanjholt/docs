---
title: "Universal Search"
api: "GET /api/v1/search"
description: "Search across all federal datasets simultaneously."
---

Perform a global text search to find references to a specific company, individual, or query across contracts, lobbying, grants, contributions, and parliament.

### Query Parameters

<ParamField query="query" type="string" required>
  The search term or phrase (e.g., `"Green Energy"`, `"Jane Doe"`).
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Maximum number of search results to return across all categories. Maximum limits map to your plan (50 for Basic, 500 for Pro, 5,000 for Enterprise).
</ParamField>

<ParamField query="type" type="string">
  Restrict search to a specific dataset type (e.g., `contracts`, `lobbying`). If omitted, searches all available datasets.
</ParamField>

<RequestExample>

```bash cURL
curl "https://api.northaxiumdata.ca/api/v1/search?query=Green+Energy&limit=5" \
  -H "X-API-Key: <your-api-key>"
```

```python Python
import requests

url = "https://api.northaxiumdata.ca/api/v1/search"
headers = {"X-API-Key": "<your-api-key>"}
params = {
    "query": "Green Energy",
    "limit": 5
}

response = requests.get(url, headers=headers, params=params)
print(response.json())
```

```javascript Node.js
const fetch = require('node-fetch');

const url = new URL('https://api.northaxiumdata.ca/api/v1/search');
url.search = new URLSearchParams({
  query: 'Green Energy',
  limit: '5'
});

fetch(url, {
  headers: {
    'X-API-Key': '<your-api-key>'
  }
})
  .then(res => res.json())
  .then(json => console.log(json));
```
