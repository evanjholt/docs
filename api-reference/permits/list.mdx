---
title: "Building Permits"
api: "GET /api/v1/permits"
description: "Retrieve a list of commercial, residential, and industrial building permits issued across Canada."
---

Get a standardized list of building permits aggregated from municipalities, filterable by municipality, text search, permit metadata, and update window.

### Query Parameters

<ParamField query="limit" type="integer" default="100">
  Maximum number of permits to return. Maximum limits map to your plan (100 for Basic, 1,000 for Pro, 10,000 for Enterprise).
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Number of records to skip for pagination.
</ParamField>

<ParamField query="municipality" type="string">
  Filter permits by issuing municipality slug. Comma-separated values are accepted.
</ParamField>

<ParamField query="q" type="string">
  Partial match across the permit search surface, including address, neighbourhood, work description, raw and canonical permit type, building type, and applicant or contractor names where available.
</ParamField>

<ParamField query="permit_type" type="string">
  One of `new_construction`, `renovation`, `addition`, `demolition`, `change_of_use`, or `other`.
</ParamField>

<ParamField query="permit_type_raw" type="string">
  Partial match on the municipality's raw permit type or class text.
</ParamField>

<ParamField query="status" type="string">
  One of `issued`, `in_review`, `completed`, `cancelled`, or `expired`.
</ParamField>

<ParamField query="building_type" type="string">
  Partial match on the normalized building or property type text.
</ParamField>

<ParamField query="neighbourhood" type="string">
  Partial match on neighbourhood, ward, or district text where available.
</ParamField>

<ParamField query="applicant" type="string">
  Partial match on `applicant_name`.
</ParamField>

<ParamField query="contractor" type="string">
  Partial match on `contractor_name`.
</ParamField>

<ParamField query="issued_after" type="string">
  ISO 8601 start date.
</ParamField>

<ParamField query="issued_before" type="string">
  ISO 8601 end date.
</ParamField>

<ParamField query="updated_after" type="string">
  ISO 8601 start date for the record's `last_updated` timestamp.
</ParamField>

<ParamField query="updated_before" type="string">
  ISO 8601 end date for the record's `last_updated` timestamp.
</ParamField>

<ParamField query="sort_by" type="string" default="date">
  One of `date`, `issued_date`, `application_date`, `updated`, `value`, or `distance`. `distance` requires `lat`, `lng`, and `radius_km`.
</ParamField>

<ParamField query="sort_order" type="string" default="desc">
  Either `asc` or `desc`.
</ParamField>

<ParamField query="lat" type="number">
  Latitude for proximity search. Must be provided with `lng` and `radius_km`.
</ParamField>

<ParamField query="lng" type="number">
  Longitude for proximity search. Must be provided with `lat` and `radius_km`.
</ParamField>

<ParamField query="radius_km" type="number">
  Radius in kilometres for proximity search. Must be between `0.1` and `100`.
</ParamField>
