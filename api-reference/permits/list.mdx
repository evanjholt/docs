---
title: "Building Permits"
api: "GET /api/v1/permits/list"
description: "Retrieve a list of commercial, residential, and industrial building permits issued across Canada."
---

Get a standardized list of building permits aggregated from municipalities, filterable by city, year, and value.

### Query Parameters

<ParamField query="limit" type="integer" default="100">
  Maximum number of permits to return. Maximum limits map to your plan (100 for Basic, 1,000 for Pro, 10,000 for Enterprise).
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Number of records to skip for pagination.
</ParamField>

<ParamField query="city" type="string">
  Filter permits by issuing municipality.
</ParamField>

<ParamField query="year" type="integer">
  Filter by the year the permit was issued (e.g., `2023`).
</ParamField>

<RequestExample>

```bash cURL
curl "https://api.northaxiumdata.ca/api/v1/permits/list?limit=10&city=Toronto" \
  -H "X-API-Key: <your-api-key>"
```

```python Python
import requests

url = "https://api.northaxiumdata.ca/api/v1/permits/list"
headers = {"X-API-Key": "<your-api-key>"}
params = {
    "limit": 10,
    "city": "Toronto"
}

response = requests.get(url, headers=headers, params=params)
print(response.json())
```

```javascript Node.js
const fetch = require('node-fetch');

const url = new URL('https://api.northaxiumdata.ca/api/v1/permits/list');
url.search = new URLSearchParams({
  limit: '10',
  city: 'Toronto'
});

fetch(url, {
  headers: {
    'X-API-Key': '<your-api-key>'
  }
})
  .then(res => res.json())
  .then(json => console.log(json));
```
