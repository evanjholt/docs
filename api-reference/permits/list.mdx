---
title: "Building Permits"
api: "GET /api/v1/permits"
description: "Retrieve a list of commercial, residential, and industrial building permits issued across Canada."
---

Get a standardized list of building permits aggregated from municipalities, filterable by city, year, and value.

### Query Parameters

<ParamField query="limit" type="integer" default="100">
  Maximum number of permits to return. Maximum limits map to your plan (100 for Basic, 1,000 for Pro, 10,000 for Enterprise).
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Number of records to skip for pagination.
</ParamField>

<ParamField query="municipality" type="string">
  Filter permits by issuing municipality slug. Comma-separated values are accepted.
</ParamField>

<ParamField query="q" type="string">
  Partial match on address or work description.
</ParamField>

<ParamField query="permit_type" type="string">
  One of `new_construction`, `renovation`, `addition`, `demolition`, `change_of_use`, or `other`.
</ParamField>

<ParamField query="status" type="string">
  One of `issued`, `in_review`, `completed`, `cancelled`, or `expired`.
</ParamField>

<ParamField query="issued_after" type="string">
  ISO 8601 start date.
</ParamField>

<ParamField query="issued_before" type="string">
  ISO 8601 end date.
</ParamField>

<ParamField query="lat" type="number">
  Latitude for proximity search. Must be provided with `lng` and `radius_km`.
</ParamField>

<ParamField query="lng" type="number">
  Longitude for proximity search. Must be provided with `lat` and `radius_km`.
</ParamField>

<ParamField query="radius_km" type="number">
  Radius in kilometres for proximity search. Must be between `0.1` and `100`.
</ParamField>
